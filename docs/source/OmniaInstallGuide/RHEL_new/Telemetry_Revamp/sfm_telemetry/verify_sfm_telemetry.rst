Verify SFM Telemetry
=====================

Verification steps for SFM telemetry are included in the :doc:`sfm_victoriametrics_integration` document.

To verify SFM telemetry data in VictoriaMetrics, refer to the "View Collected SFM Telemetry Data using VictoriaMetrics UI (VMUI) - Cluster Mode Deployment" section in the SFM VictoriaMetrics Integration documentation.

.. note:: No additional SFM-specific verification steps are documented beyond the VictoriaMetrics UI verification included in the integration guide.
